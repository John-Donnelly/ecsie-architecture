The transformer architecture, introduced in 2017, replaced recurrent networks as the dominant approach to sequence modeling. Its central mechanism is self-attention, which allows every position in a sequence to attend to every other position in parallel, rather than processing tokens one at a time. This parallelism made it possible to train far larger models on far larger datasets than were previously practical, and it underlies essentially every large language model in use today.

A transformer is built from a stack of identical blocks. Each block contains a multi-head attention layer followed by a position-wise feed-forward network, with residual connections and layer normalization applied around both sublayers. The attention layer computes three projections of its input, called queries, keys, and values. The dot product of a query with each key produces a score; these scores are scaled, passed through a softmax to form a probability distribution, and used to take a weighted average of the values. Multiple attention heads run in parallel, each learning to focus on a different kind of relationship between tokens.

Mixture-of-experts models extend this design by replacing the dense feed-forward network with a large collection of smaller expert networks. For each token, a lightweight router selects only a few experts to activate, so the model can have a very large total parameter count while keeping the computation per token small. This sparsity is what allows a thirty-billion-parameter mixture-of-experts model to run at speeds comparable to a much smaller dense model, because only a fraction of the weights participate in any given forward pass.

Quantization reduces the memory and bandwidth cost of these models by storing weights at lower numerical precision. Instead of sixteen bits per weight, a quantized model might use four bits, or even fewer, grouped into blocks that share a scaling factor. The challenge is to preserve accuracy: aggressive quantization can distort the model's predictions, especially in the later layers where the representation is closest to the final output. Careful schemes protect the most sensitive weights at higher precision while compressing the rest, trading a small amount of memory for a large reduction in error.

Speculative decoding accelerates generation by using a small, fast draft model to propose several tokens at once, which the large target model then verifies in a single parallel pass. When the draft is correct, multiple tokens are produced for the cost of one forward pass; when it is wrong, the model falls back to standard decoding. The technique is most effective when the draft model is both cheap to run and accurate enough that its proposals are frequently accepted.
